Oversized yellow hero figure for value posts (e.g. "730 GÜN"). One per post, near the top.

```jsx
<StatNumber value="730" unit="GÜN" />
<StatNumber value="¼" unit="CEZA" unitTone="white" />
```

- The number is always yellow; `unitTone` sets the suffix color (`accent` | `white`).
- Override `size` (a CSS length) to fit longer figures.
